# ClinicFlow User Stories

1. As a receptionist, I want to add a new clinic visit so that the care team knows when a patient has arrived.

2. As a receptionist, I want to view all current clinic visits so that I can monitor which patients are waiting.

3. As a receptionist, I want to edit incorrect visit information so that clinic records remain accurate.

4. As a receptionist, I want to delete duplicate or incorrect visits so that the visit list stays accurate.

5. As a nurse, I want to update a visit status so that other staff can see where the patient is in the clinic workflow.

6. As a physician, I want to view patients who are waiting or currently with a provider so that I can understand the current patient flow.
