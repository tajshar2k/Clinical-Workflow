# Clinical-Workflow Project Overview

## Project Purpose
ClinicFlow is a web-based clinic visit tracking application designed to help outpatient clinic staff manage and monitor patient visits.

## Target Users
The primary users are:
- Receptionists
- Nurses
- Clinic administrators
- Physicians

## Problem Being Solved
The clinic staff need a simple way to track patient visits, update visit information, and monitor where a patient is in the clinic workflow.

## Main Features
The application will allow users to:
- View clinic visits
- Add a new visit
- Update visit information
- Delete an incorrect visit
- Track visit status of patients

## Technology Stack
- Angular frontend
- Node.js backend
- Express API
- Azure SQL database
- Bootstrap for styling
- GitHub for source control

## Project Scope
The application will focus only on clinic visit tracking. I will use fictional patient data which does not include real patient information, billing or other authentication information
