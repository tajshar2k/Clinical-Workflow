# ClinicFlow User Requirements

##  Requirements

1. The system must allow clinic staff to view all clinic visits.

2. The system must allow clinic staff to add a new visit.

3. The system must allow clinic staff to update an existing visit.

4. The system must allow clinic staff to delete an incorrect or duplicate visit.

5. The system must allow clinic staff to update the status of a visit.

6. The system must store visit information in a database.

7. The system must retrieve and update data through a backend API.

8. The system must display visit information in a clear web-based interface.

9. The system must use fictional patient information only.

10. The application must be accessible through a public web URL.

11. The application should have a simple and easy-to-use interface.

12. The application should provide clear feedback when records are added, updated, or deleted.

13. The application should handle invalid input without crashing.

14. The application should keep database credentials hidden from the frontend and public source code.
